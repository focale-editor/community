# Reporting a security vulnerability

Email [contact@focale-editor.app](mailto:contact@focale-editor.app) with the subject
`Focale security report`. Please avoid opening a public issue for a vulnerability
or posting details that would expose other users.

Include the affected version, platform, reproduction steps and potential impact.
Share a minimal example with sensitive data removed. We can discuss further
details privately before public disclosure.

For ordinary crashes, visual bugs and feature requests, use the
[public issue forms](https://github.com/focale-editor/community/issues/new/choose).
